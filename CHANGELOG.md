# Changelog

All notable changes to **AI Commerce Agent Toolkit** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.6.0] — 2024-01-20

### Added
- Multi-harness plugin manifests for Claude Code, Cursor, Codex, VS Code, Hermes, Gemini, Pi, and Antigravity
- Twenty-one commerce agent skills covering Admin, Storefront, Liquid, Polaris surfaces, POS, Hydrogen, Partner, Payments, ShopifyQL, CLI, onboarding, and UCP
- Docs search and schema validation scripts for the agent generate/validate loop
- Optional usage telemetry with environment opt-out

### Changed
- Project identity rebranded to AI Commerce Agent Toolkit
- Documentation rewritten for independent open-source distribution

### Fixed
- Install path matchers aligned with the new repository and plugin slugs

## [Unreleased]

### Planned
